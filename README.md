# Number Guessing Game

## 📌 Project Description

The Number Guessing Game is a Java console-based game in which the computer generates a random number between 1 and 100, and the player tries to guess it.

The game provides hints such as "Too High!" and "Too Low!" after each guess. The player has a maximum of 7 attempts to guess the correct number.

After each round, the player can choose whether to play again.

## ✨ Features

- Generates a random number between 1 and 100
- Takes user input using Scanner
- Provides Too High / Too Low / Correct feedback
- Tracks the number of attempts
- Maximum of 7 attempts per round
- Displays "You Lost!" when the maximum attempts are reached
- Reveals the correct number after losing
- Supports multiple rounds
- Provides a Play Again option
- Displays round and attempt information
- Validates guesses outside the 1–100 range

## 🛠️ Technologies Used

- Java
- Java Random
- Java Scanner
- do-while loop
- Conditional statements
- Variables and data types
