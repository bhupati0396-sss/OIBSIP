# Calculator App

This is a simple calculator Android application developed as part of my Java Development Internship at Oasis Infobyte.

The app can perform basic mathematical calculations and has a simple button-based interface.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal numbers
- Clear button (C)
- Backspace button
- Equals button (=)
- Shows an error when dividing by zero
- Simple and easy-to-use interface

## Technologies Used

- Java
- XML
- Android Studio

## How to Use

1. Open the Calculator app.
2. Enter the first number.
3. Select an operator such as +, -, ×, or ÷.
4. Enter the second number.
5. Press the `=` button to get the answer.
6. Use `C` to clear the calculation.
7. Use the backspace button to remove the last digit.
